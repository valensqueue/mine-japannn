7. Grammar

ประมาณบท 133–170

ต้องสอน Grammar แบบเป็นขั้น ไม่ใช่แค่แสดงสูตร

ตัวอย่างหัวข้อ:

Basic sentence

- A は B です
- A は B じゃありません
- A は B ですか

Particles

- は
- が
- を
- に
- で
- へ
- と
- も
- の
- から
- まで

ข้อควรจำ:

- は เมื่อเป็น particle อ่านว่า wa
- を อ่านว่า o
- へ เมื่อเป็น particle อ่านว่า e

Verbs

- あります
- います
- です
- กริยาพื้นฐาน

จำแนก:

- あります = สิ่งไม่มีชีวิต
- います = สิ่งมีชีวิต

Adjectives

- い-adjective
- な-adjective

ต้องระวัง:

- きれい เป็น な-adjective

Forms

- Dictionary form
- ます form
- ない form
- て form

กฎสำคัญ:

て-form Group 1

- う / つ / る → って
- ぬ / ぶ / む → んで
- く → いて
- ぐ → いで
- す → して

Exception:

- いく → いって

Group 2

- る → て

Irregular

- する → して
- くる → きて

ない-form

Group 1:

- u-ending → a-row + ない
- う → わない

Group 2:

- る → ない

Irregular:

- する → しない
- くる → こない

Expressions

- ～ないでください = กรุณาอย่า...
- ～なければなりません = ต้อง...
- ～なくてもいい = ไม่ต้อง...
- ～てもいいですか = ขออนุญาต...ได้ไหม
- ～てはいけません = ห้าม...

Grammar ต้องมี:

- Explanation
- Example
- Audio
- Practice
- Quiz

9. รูปแบบ “หนึ่งบทเรียน”

นี่เป็นส่วนสำคัญมาก

เมื่อกดเข้า Lesson ต้องไม่ใช่หน้าเดียวที่มีข้อมูลทั้งหมด

ต้องเป็น Guided Lesson / Multi-step Lesson

ลำดับประมาณ:

STEP 1 — Intro

แสดง:

- ตัวอักษร / คำศัพท์ / Grammar
- Romaji
- คำอ่านไทย
- ชื่อบท
- คำอธิบายสั้น ๆ

STEP 2 — Explanation

อธิบายสิ่งที่กำลังเรียน

STEP 3 — Listen

- ฟังเสียง
- Replay
- Slow playback
- แสดงสิ่งที่กำลังฟัง

STEP 4 — Reading

ให้ผู้เรียนลองอ่าน

- แสดงตัวอักษร/คำ
- Romaji
- Thai pronunciation
- ตัวเลือกคำตอบ

STEP 5 — Stroke Order

สำหรับ Kana:

- แสดงลำดับขีดจริง
- มี animation
- มีหมายเลขลำดับขีด
- สามารถ Replay animation ได้

ไม่เอาแค่เส้น placeholder ที่ดูเหมือนขยับ

STEP 6 — Writing

มี Canvas สำหรับ:

- ลากเขียน
- Trace ตามเส้น guide
- ตรวจ/ให้ feedback เบื้องต้น
- Clear
- Try again

STEP 7 — Quiz

- หลายข้อ
- Multiple choice
- ตรวจคำตอบ
- แสดง feedback
- คะแนน
- Progress ของ Quiz

STEP 8 — Result

เมื่อจบบท:

- Score
- จำนวนข้อถูก
- จำนวนข้อทั้งหมด
- Best score
- สถานะผ่าน
- ปลดล็อกบทถัดไป
- ปุ่มไปบทถัดไป

10. ระบบ Progress

progress = {
  completedLessons: [1, 2, 3, 4, 5],
  currentLesson: 6,
  scores: {
    1: 100,
    2: 80,
    3: 100

      あ: true,

- Progress ต้องไม่หาย

30. เป้าหมายสุดท้าย

เว็บควรให้ความรู้สึกว่า:

«“นี่คือแอปเรียนภาษาญี่ปุ่นของกู”»

ไม่ใช่:

«“นี่คือเว็บที่เอาข้อมูลภาษาญี่ปุ่นมาใส่ไว้หลายหน้า”»

ผู้ใช้ควรสามารถเปิดเว็บ → เริ่มบท 01 → เรียนทีละขั้น → ทำแบบฝึก → สอบ → ผ่าน → ปลดล็อกบท 02 → กลับมาเรียนต่อวันอื่น → ดู Progress ได้

ทั้งหมดต้องทำงานต่อเนื่องในเว็บเดียว
